
# Car & Motorcycle Rental System

A simple car and motorcycle renting system with an admin panel and a user interface.

## Features
- User interface for browsing and renting vehicles
- Admin panel for managing vehicles and rentals
- Database-backed system using MySQL

## Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS, JavaScript

## Requirements
- PHP (XAMPP/WAMP/LAMP or any PHP server)
- MySQL / phpMyAdmin
- Web browser
